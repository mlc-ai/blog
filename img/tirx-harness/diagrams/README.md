# TIRx Harness component diagrams

These interactive HTML diagrams and their shared CSS/JavaScript are copied from
[Agentic GPU Programming for MLSys](https://mlc.ai/agentic-gpu-programming-for-mlsys/)
(`_static/diagrams/`, retrieved September 29, 2026).

- `tirx-lite-layers.html`: TIRx compiler foundation.
- `analysis-overview.html`: domain-specific compiler analysis.
- `knowledge-base.html`: kernel and hardware knowledge.
- `kcoral.html`: benchmark server components and deployment.

Keep dependencies local: `diagrams.css`, `overview.css`, and `diagrams.js`.
The shared script resizes each same-origin iframe as its content changes.
